# 统计方法说明：连续监控下的实验分析

产品实验每天看结果、中途停流量或改分配，是**序贯决策**场景。本文说明平台选用的方法、
为什么固定样本检验不能直接用、以及敏感性（power）与决策延迟的权衡。

## 1. 问题：固定样本检验不能每天反复用

固定样本 z 检验的 α=5% 误报率只在「预先定好样本量、到时看一次」下成立。
每天看一次、显著就停，相当于做了 14 次多重检验，误报率大幅膨胀。

本平台蒙特卡洛实测（`tests/test_stats.py`，零假设、每天 1500/组、14 天、3000 次模拟）：

| 决策方式 | 任意时刻误报率 |
|---|---|
| 裸 z 检验，每天看，\|z\|≥1.96 就停 | **22.2%** |
| mSPRT（always-valid），每天看，想停就停 | **0.8%**（≤ α=5%） |
| 组序贯 OBF α 消耗 | ≈ 5%（见测试断言区间） |

结论：每日盯盘的团队必须换用对**可选停时（optional stopping）**有效的方法。

## 2. 主方法：mSPRT（混合序贯概率比检验）

对效应差 θ（处理转化率 − 对照转化率），令 θ̂ ~ N(θ, 1/V)，V 为观察精度（1/se²）。
取混合备择 H₁: θ ~ N(0, τ²)，对 H₀: θ = 0 的混合似然比：

```
Λ = (1 + V·τ²)^(-1/2) · exp( θ̂²·V²·τ² / (2·(1 + V·τ²)) )
```

在 H₀ 下 {Λ} 是非负鞅，由 Ville 不等式：**P(存在任意时刻 t: Λ_t ≥ 1/α) ≤ α**。
因此：

- **always-valid p 值**：p_t = min(1, min_{s≤t} 1/Λ_s)。任何时刻看、任何时刻停，
  用 p_t ≤ α 做拒绝，总体一类错误仍 ≤ α。看多少次、什么时候看，都不影响有效性。
- **置信序列（confidence sequence）**：把检验反演，得到随时间变窄的漏斗形区间
  `θ̂ ± w`，`w² = (1+Vτ²)/(V²τ²) · (ln(1+Vτ²) + 2·ln(1/α))`。
  P(所有时刻真效应都在区间内) ≥ 1−α。区间整体穿出 0 即显著。

**检查链的实现**：每次分析 run 是信息时间上的一次检查，绑定当时的数据水位线；
p 值链按（实验 × 指标 × 指标版本）维护滚动最小。指标换版 = 换了假设，链重启
（旧链结果保留在旧版本的 run 里）。轨迹回放（含迟到数据的重算）只用于可视化，
不作为决策依据 —— 决策依据是各次 run 当时算出的 Λ。

## 3. 备选：组序贯（Lan-DeMets α 消耗）

若组织要求「预定检查计划」，平台同时给出组序贯边界作为对照：

- 信息比例 t = 当前精度 V / 计划终点精度 V_planned。
- 消耗函数：OBF 型 `α*(t) = 2(1 − Φ(z_{α/2}/√t))`；Pocock 型 `α*(t) = α·ln(1+(e−1)t)`。
- 各次检查的 z 边界由独立增量递推数值积分求得（`statsutil.gsd_boundaries`），
  与标准表（如 OBF K=4 ≈ 4.05/2.86/2.34/2.02）误差 ~0.02。
- 检查点 = 实际发生的 run；检查时间不必等距（Lan-DeMets 只依赖信息比例）。

## 4. 敏感性 vs 决策延迟

没有免费的午餐：守住任意时刻 α 的代价是边界比固定样本的 1.96 更宽，即**同等样本下
更保守**（或同等 power 下需要更多样本）。可调的三处权衡：

| 旋钮 | 更敏感（早停快） | 更保守（延迟决策） |
|---|---|---|
| mSPRT 的 τ | τ ≈ 真实效应量级（默认 τ=MDE，对 MDE 效应最敏感） | τ 远大于真实效应：边界变宽，停得晚 |
| 消耗函数 | Pocock：各次边界接近水平，早期容易停 | OBF：早期边界极高（几乎不停），α 留到终点，终点检验最接近固定样本的敏感度 |
| 计划信息量 | 计划流量/天数越大，MDE 越小，越晚才能下结论 | — |

经验法则：真实效应 ≥ MDE 时，信息量过半通常即可越界；真实效应远小于 MDE 时会
观察到计划终点。提前停还有**赢家魔咒**：停边界处的 θ̂ 系统性偏高，引用结论时应看
置信序列区间而非点估计。

## 5. 数据语义：迟到、撤销、切流量、并发

- **水位线快照**：事件 append-only，`seq` 为摄入水位线。每次 run 先固定
  `as_of_seq` 再计算，计算期间并发摄入不影响本 run；任何历史水位线都可复算。
- **迟到与撤销参与重算**：迟到事件（event_time 早、seq 晚）随水位推进自动进入
  后续 run；撤销是 tombstone 事件（`revoke` 指向原事件），重算时按水位线内的
  撤销集合剔除。历史 run 的结果不变（不可变），新 run 反映新数据。
- **切流量不重置观察窗**：`allocation_change` 只产生 epoch 记录（页面标注），
  观察窗永远是 [实验开始, 数据地平线]。注意：非 50/50 分配会降低信息积累速度
  （精度 V 由小组样本量主导），平台的信息量 t 如实反映这一点。
- **结论绑定**：每个 run 记录（水位线 seq、指标版本、方法版本、全部参数）。
  决策必须引用 run；确认时若 run 的水位线早于当前已确认决策的水位线，
  拒绝（HTTP 409）并写入审计表 —— 迟到的旧任务不能改写已确认决策。
  新决策只能以更新水位的 run 取代旧决策（旧决策置 superseded，历史保留）。

## 6. 局限与措辞规范（不夸大）

- 比例指标 + 正态近似：样本量小或转化率接近 0/1 时近似变差；置信序列与 p 值
  在该区域偏乐观。平台按去重用户聚合，未做方差缩减（CUPED）与分层。
- 「未检出 ≥MDE 的效应」≠「无效应」：置信序列半宽大于 MDE 时，对小效应不敏感。
- 提前停的 θ̂ 偏高估；报告效应时请引用置信序列。
- 多指标/多实验同时看时，本平台的 α 控制是**单指标链**级别的，不做跨指标族系校正。
- 序贯方法控制的是一类错误；二类错误（漏报）由信息量决定，页面以信息量 t 与
  置信序列半宽如实展示。
